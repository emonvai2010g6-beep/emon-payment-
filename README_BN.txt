PayVerify — বাংলা ডেমো পেমেন্ট ভেরিফিকেশন ওয়েবসাইট

ফাইল:
- index.html: ব্যবহারকারীর পেমেন্ট ফর্ম
- admin.html: ডেমো অ্যাডমিন প্যানেল
- style.css: ডিজাইন
- app.js/admin.js: ব্রাউজারে ডেমো ডেটা সংরক্ষণ

গুরুত্বপূর্ণ সীমাবদ্ধতা:
১) এই ZIP-টি সামনের দিকের ডেমো। ফর্মের তথ্য localStorage-এ, অর্থাৎ একই ব্রাউজার/ডিভাইসে থাকে।
২) আলাদা ব্যবহারকারীর ফোন থেকে জমা দেওয়া আবেদন আপনার অ্যাডমিন প্যানেলে পৌঁছাবে না।
৩) পাসওয়ার্ডও শুধু একই ব্রাউজারে ডেমোভাবে রাখা হয়; এটি নিরাপদ সার্ভার-সাইড লগইন নয়।
৪) GitHub Pages-এ admin.html প্রকাশ করলে পৃষ্ঠাটি সবার জন্য দেখা যায়; গোপন তথ্য রাখবেন না।
৫) বাস্তব ব্যবহারের জন্য সার্ভার/ডেটাবেস, নিরাপদ অ্যাডমিন অথেনটিকেশন, HTTPS এবং সার্ভার-সাইড ভ্যালিডেশন লাগবে।
৬) বিকাশ/নগদে টাকা সত্যিই এসেছে কি না, শুধু TrxID দেখে নিশ্চিত ধরে নেবেন না। আপনার লেনদেনের হিস্ট্রি থেকে যাচাই করুন। PIN/OTP কখনও সংগ্রহ করবেন না।

স্থানীয়ভাবে পরীক্ষা:
index.html ফাইল খুলুন। একই ব্রাউজারে admin.html খুলে কমপক্ষে ৬ অক্ষরের ডেমো পাসওয়ার্ড সেট করুন। ফর্মের আবেদন অ্যাডমিন প্যানেলে একই ব্রাউজারে দেখা যাবে।

GitHub Pages:
ফাইলগুলো GitHub repository-তে আপলোড করে Settings > Pages থেকে প্রকাশ করা যায়। মনে রাখবেন, এটি ডেমো; বাস্তব পেমেন্ট আবেদন গ্রহণের জন্য ব্যাকএন্ড যুক্ত করতে হবে।
